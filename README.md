# MC-Java-Reforged

JavaReforged is a Minecraft Java Edition overhaul focused on improving the local multiplayer, controller and user-interface experience.

The project aims to provide a more console-like and customizable experience while still running on Minecraft Java.

## Planned features

- Split-screen multiplayer in a single Minecraft instance
- Full controller support
- Redesigned menus, HUD and gameplay screens
- Per-player interfaces and input
- Custom UI DSL for defining scenes, screens and reusable UI components
- Improved support for local multiplayer workflows

## Current status

JavaReforged is currently in early experimental development.

Split-screen support is already functional with up to 4 local players, but many systems are still being developed, redesigned or tested.

A public alpha is planned for testing and feedback.
